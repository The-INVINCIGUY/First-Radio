#First-Radio

This is my first project involving RF (radio frequency), and my first PCB design with a component mounted on the back of the board. The design uses an SX1281-based radio module for 2.4 GHz wireless communication. This module has a U.FL connector, and I am planning to make use of it. This small project also includes a small OLED for menus and status information, along with a combined navigation switch and rotary encoder for user input.

The whole design is complete, but I'm thinking about making a second PCB revision to remove the component on the back to make assembly easier and make it slightly bigger so it doesn't look like a small square. I've never designed anything to do with RF before, so it'll be interesting to see how well the module and my design works.
