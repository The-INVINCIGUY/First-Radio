# First Radio

This is my first project involving RF, and my first PCB design with a component on the back of the board. It uses an SX1281-based radio module for 2.4 GHz wireless communication. The module has a U.FL connector, which I plan to use for an external antenna.

The main MCU is an RP2354, which lets me add external PSRAM for extra memory and (hopefully) do some complex compression stuff with it.

The project also has a small OLED which I plan to use for showing a bunch of radio-related things, along with a combined joystick and rotary encoder for controls (was expensive, but worth it for the size and coolness).

The design is complete, but I'm thinking about making a second revision. I'd like to remove the component on the back to make assembly more straightforward, and maybe make the whole thing a bit bigger so it looks and feels more like a regular walkie-talkie. I wish I could have both the compact size and the comfort of a bigger design, but I still quite like how small it is now.

I've never designed anything even loosely related to RF before, so I'm interested to see how well it all works IRL.
